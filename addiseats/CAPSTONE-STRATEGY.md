# Capstone Migration Strategy

The AddisEats capstone is migrated screen by screen into Next.js App Router.

1. Home - `/`
2. Menu - `/menu`
3. Favorites - `/favorites`
4. Cart - `/cart`
5. Orders - `/orders`
6. Order confirmation - `/order-confirmation/[id]`
7. Mobile flow - `/mobile-flow`

Each screen is reachable through the application header, normal links, or the relevant flow action.
